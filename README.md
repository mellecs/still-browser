Still Browser

Still Browser is a desktop web browser built with Electron, designed to provide a simple and minimalist browsing experience.

«Browse, nothing more.»

Features

- Web browsing powered by Chromium.
- Desktop interface built with Electron.
- Tabbed browsing.
- Simple and lightweight design.
- Modern and easy-to-use interface.

Technologies

- Electron — Framework for building desktop applications with web technologies.
- HTML / CSS / JavaScript — Used for the interface and application logic.
- Chromium — Browser engine used for web browsing.

Creator

Still Browser was created by melle.

Project Status

Still Browser is currently in development.
Features may change, and some parts of the browser may be incomplete or contain bugs.
